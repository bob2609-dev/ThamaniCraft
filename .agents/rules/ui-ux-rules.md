# UI/UX Design Rules - AG Kit

> Always-active rules for UI/UX design in this project.

---

## 1. Modals (No Vertical Scrolling)
- Modals must be designed to avoid vertical scrolling.
- Utilize horizontal space effectively by arranging form fields in columns or grids (e.g., side-by-side inputs) rather than a single vertical column.
- Keep modal heights compact and ensure all actions are visible without scrolling.

## 2. Tables (No Horizontal Scrolling)
- Tables must be designed to avoid horizontal scrolling.
- Limit the number of columns to essential data.
- Use responsive table techniques (e.g., ellipsis for long text, collapsible rows, or card-based views on mobile) instead of forcing a horizontal scrollbar.

## 3. Responsive Design (Mobile First)
- All pages and components MUST consider smaller screens and mobile responsiveness.
- Use responsive grids and fluid layouts. Ensure tables, forms, and navigation adapt gracefully to narrow viewports.
