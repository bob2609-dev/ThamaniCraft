# ThamaniCraft

> **Vertical SaaS ERP & Production Management Platform for Bakeries, Food Producers, and Craft Manufacturers in East Africa.**

Built with **ReactJS (Vite)** frontend and **Java Spring Boot 3** microservices, containerized with Docker and reverse-proxied via Nginx.
